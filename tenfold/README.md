# Tenfold

Tenfold is a dependency-free interactive math workshop for grade 3 learners. It turns addition facts, regrouping, and borrowing into visual actions before asking for symbolic answers.

## Open the app

Open `index.html` in a browser. For the most reliable local experience, serve this folder with any static web server.

## Learning labs

- **Add & explore:** change either addend, inspect the counters, select any addition-table cell, and solve row/column challenges.
- **Regroup:** solve four-digit addition one place at a time and exchange ten small pieces for one larger-place piece.
- **Borrow:** solve four-digit subtraction by exchanging one larger-place piece for ten smaller pieces.
- **Practice:** complete five mixed problems with optional conceptual hints, a streak, and locally saved XP.

Progress stays in the browser. The app has no account, tracking, or backend.

## Accessibility

The interface supports keyboard navigation, large touch targets, visible focus, live announcements, non-color-only instructions, and reduced-motion preferences.
